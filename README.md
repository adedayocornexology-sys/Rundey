# Rundey

Hyperlocal commerce and rider logistics app for Nigerian cities.

## What is Rundey?

Rundey connects customers to local businesses and riders for fast, 
reliable delivery within their city. Built for Owo and Akure first, 
designed to scale across Nigeria.

## The Three Layers

- **Layer 1 — Commerce & Riders**: Browse local businesses, place orders, 
  track riders in real time, get things delivered fast.
- **Layer 2 — AI Activity Feed**: Claude-powered local intelligence — 
  discover what's happening around you, personalized to your city.
- **Layer 3 — Anomaly Tracking**: Community safety layer that detects 
  unusual patterns in city activity.

## Who It Serves

- **Customers** — order from local vendors, track delivery live
- **Merchants** — list products, receive orders, manage catalogue
- **Riders** — get dispatched, navigate pickups, earn money

## Tech Stack

- React Native + Expo
- Supabase (PostGIS + pgvector)
- Node.js
- Paystack
- Claude Haiku (Anthropic API)
- Railway
